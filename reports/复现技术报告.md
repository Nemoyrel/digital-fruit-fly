# 数字果蝇：Eon 具身果蝇复现

---

## 一、项目定位

**目标**：复现 Eon Systems 发布的首个多行为具身脑-体闭环仿真（数字果蝇）。  
**路线**：整合两个公开科学组件，开发必要连接层，复现数字果蝇的行为与神经活动。

| 组件 | 来源 |
|------|------|
| 脑模型 | Shiu et al., *Nature* 2024 / FlyWire Connectome v783 |
| 身体模型 | FlyGym 2.0.2 / NeuroMechFly（EPFL NeLy Lab） |

---

## 二、技术架构

### 双进程 · 双环境

身体与脑运行在两个相互冲突的 Python 环境，无法共处同一进程：

```
brain_env   ──  Brian2 LIF 仿真 + Cython JIT
flygym_env  ──  FlyGym/MuJoCo 物理仿真 + 渲染
```

### 模块结构

```
src/digital_fruit_fly/
├── brain/      OnlineBrain · NeuronIDs · Backend
├── body/       FlyBody · Arena · Sensing · MotorController · Loop
├── bridge/     IPC · Messages
└── viz/        BrainPanel · Compositor
```

## 四、行为系统与下行神经元（DN）驱动

三行为状态机：**觅食 → 进食 → 梳理**，由脑侧 DN 读出仲裁。

| 行为 | 触发感觉输入 | 脑侧读出神经元 | 驱动方式 |
|------|-------------|----------------|----------|
| 转向 | 嗅觉 ORN（双侧非对称） | DNa01 / DNa02（L/R 差分） | 差分频率 → 步态偏转增益 |
| 前进 | 嗅觉 ORN（双侧对称） | oDN1（DNg97） | 频率 → 步态前进增益 |
| 进食 | 味觉 GRN（接触食物） | MN9（喙运动神经元） | 涌现通路触发，停步 + 前腿摆动 |
| 梳理 | 机械感受 JON-CE/F（灰尘积累） | aBN1 → aDN1（DNg62）/ aDN2（DNge078） | 前馈通路触发，前腿高频对搓 |

> 身体为 **legs-only** 构型（无喙/触角执行机构），进食与梳理动作由前腿关节角覆写近似实现。

## 五、关键神经通路验证

### 进食通路（真实涌现）

```
糖 GRN（20 个神经元）──150 Hz──▶ 全脑传播 ──▶ MN9
潜伏期：~30 ms（2 个 15 ms 窗）
MN9 峰值：~200 Hz
```

### 梳理通路（静态 + 动态双重验证）

```
JON-CE（70）+ JON-F（60）+ JON-D_m（16）= 146 个机械感受 JON
    │  77 突触（JON-CE）/ 69 突触（JON-F）
    ▼
  aBN1（SAD093）
    │  85 突触 → aDN1（DNg62）
    │  106 突触 → aDN2（DNge078）
    ▼
 前腿梳理执行
```

动态仿真（N = 5 × 1000 ms，固定种子）：JON@140 Hz → aBN1 ~48 Hz / aDN1 ~5 Hz / aDN2 ~17 Hz；基线 = 0 Hz。

## 六、复现成果

### 端到端演示

- 仿真时长：10 s  
- 行为序列：觅食（趋向食物）→ 进食 → 梳理 → 循环

### 行为分布（遥测统计，共 100,000 步）

| 行为 | 步数 | 占比 |
|------|------|------|
| 觅食 | 45,300 | 45.3% |
| 梳理 | 38,650 | 38.7% |
| 进食 | 16,050 | 16.1% |
