# L3 Brain Lookup Integration

L3 replaces the L2 rule-only readout source with a compact offline lookup table:

```text
sensory_state -> LookupBrainBridge -> brain_readout -> behavior_state -> FlyGym body
```

## Generate The Lookup

```bash
conda activate brain_env
python scripts/generate_l3_brain_lookup.py
```

Inputs are defined in `configs/l3_brain_lookup.json`. The generated files are:

- `data/l3_brain_readout_lookup.csv`
- `data/l3_brain_readout_lookup_metadata.json`
- `outputs/l3_brain/l3_brain_readout_lookup_report.json`

## Data Sources

Sugar/MN9 rows are derived from upstream example spike parquet files in `external/drosophila_brain_model/results/example/`:

- MN9 FlyWire ID: `720575940660219265`
- `sugarR_100Hz`: MN9 mean rate about `67.0333 Hz`
- `sugarR`: MN9 mean rate about `93.2667 Hz`

Dust/grooming rows are generated by a small Brian2 LIF proxy using constants matching the style of `external/drosophila_brain_model/model.py`, including `v_0=-52 mV`, `v_th=-45 mV`, `t_mbr=20 ms`, `tau=5 ms`, `t_rfc=2.2 ms`, `w_syn=0.275 mV`, and `f_poi=250`.

This grooming proxy is not a full Shiu connectome run. It exists so L3 can demonstrate the lookup-table interface and produce a graded `grooming_score` from dust level while keeping the demo stable and fast.

## Run The Embodied Demo

```bash
conda activate flygym_env
python scripts/run_l3_embodied_demo.py --duration 6.5 --log-every-steps 50
```

The demo writes telemetry, metadata, plot, and video files under `outputs/l3_embodied_loop/`. In the validated local run, dust reached threshold at about `4.5655s`, grooming held locomotion at zero drive, and dust cleared at about `5.5656s`.

## Lookup Columns

- `input_kind`: `sugar` or `mechanosensory_dust`
- `input_value`: normalized food cue or dust level
- `stimulus_hz`: source stimulus rate used for the lookup row
- `mn9_rate_hz`: MN9 firing rate for sugar rows
- `grooming_rate_hz`: proxy LIF rate for dust rows
- `feeding_score`: normalized feeding readout
- `grooming_score`: normalized grooming readout
- `source`: provenance for the row

## Boundary

L3 is an empirical-readout integration demo, not a complete biological reproduction:

- Sugar/MN9 uses upstream model example outputs.
- Dust/grooming currently uses a documented Brian2 proxy.
- `LookupBrainBridge` interpolation, behavior priority, forward/turn drive, and FlyGym control are project engineering code.
- No L3 code adds custom head, front-leg, or proboscis actuators; visible grooming/feeding actions are left for a later stage.
